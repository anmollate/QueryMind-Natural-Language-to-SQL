You ask

"What is the total transaction amount per card network this month?"

QueryMind writes 
SELECT card_network,
       SUM(amount) AS total
FROM credit_card_transactions
WHERE transaction_date >= date_trunc('month', CURRENT_DATE)
GROUP BY card_network;
