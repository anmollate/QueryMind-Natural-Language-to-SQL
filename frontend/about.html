Schema linking strategy

No retrieval step — the full schema goes in
Schema extractionThe complete database schema — every table, column, and type — is introspected directly from the database at query time.
Full-schema promptingThe extracted schema is passed alongside the user's question to the generation model — no shortlisting or retrieval step.
Judge-validated outputThe generated SQL, its result, the question, and the schema all go to a second model that checks the answer before it's shown.
